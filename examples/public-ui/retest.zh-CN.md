## 剩余视觉差异

旧弹窗采集包缺少背景模糊参数，并包含动画中间态。新采集恢复了可编辑背景模糊，在线弹窗的残差集中在输入框焦点环、正文与背景卡片。Plane 两个状态的热图仍集中在文字和输入框边缘。Cal.com 的历史日期填充存在采集包与原图不一致的情况。

受控 Arimo 字体的 Field notes 十块画板全部通过像素门槛。独立的四状态原生弹窗夹具仍有 0/4 整板过线，清晰与模糊两组均有浏览器原生焦点环和文字差异。以上整板结果独立于组件与交互验收。

## 四层对等评测（新增口径）

为避免单行文本宽度安全余量、在线页面字体回退与脏采集混同，报告现已按四层独立输出，同时保留上方 `16/255`、≤1% 全板门槛作历史基线对照：

1. **L1 采集完整性**：记录 `captureIntegrity`（前后截图 SHA-256 一致、可见动画归零、资源就绪）。历史九板与本轮预置采集包均早于该字段写入，记为 `unrecorded`；其中历史冻结弹窗与历史在线弹窗已通过源码/截图比对确认为动画中间态或缺失背景模糊的脏采集。
2. **L2 结构与语义（硬门禁）**：历史九板 109/109 显式标记节点全部保留为原生实例，直接文本槽可编辑属性 100% 匹配（4/4、11/11、1/1、35/35），立即反向导出变更为 0；历史输入重建的 Figma Present 4 条原型连线全部可点击通过，新采集重放 3/4（Cal.com 目标时段在重放时已不可用）。
3. **L3 布局与局部视觉**：`audit` 剥离合法单行 `textFit` 补偿后，全部九板与重采画板的外层几何误差 `layoutIssues` 为 **0**，61 处历史原始超 1px 读数全部归入内部单行补偿（`compensatedFields = 61`）；已缓存导出包早于 `lineCount` 导出，故 `unknownLines` 如实记为未知。`verify` 按组件/文本/图片包围盒输出局部 ROI 统计。
4. **L4 全板像素与感知指标**：在保留 16/1% 门槛的同时补充 `SSIM` 与 `ΔE76`。重采后冻结弹窗 `SSIM` 从 `0.9625` 升至 `0.9840`（`ΔE76` 从 `1.33` 降至 `0.28`），在线打开弹窗 `SSIM` 从 `0.8592` 升至 `0.9764`（`ΔE76` 从 `4.28` 降至 `0.48`）；在线页面的字体回退与时段可用性变化仍按环境事实单独标注。

完整逐板四层指标与 HTML 对照见 `build/retest-v2/index.html` 与 `build/retest-v2/summary.json`。
